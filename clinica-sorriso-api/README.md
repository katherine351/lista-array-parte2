# 🦷 Clínica Sorriso API

API RESTful desenvolvida para alimentar o sistema de gestão da **Clínica Odontológica Sorriso**, integrando agendamentos e prontuários médicos.

## 🎯 Objetivo do Sistema
Prover rotas seguras e rápidas para a marcação de consultas odontológicas, consulta de horários disponíveis dos dentistas e controle do histórico de atendimentos dos pacientes.

## 🛠️ Tecnologias Previstas
- **Back-end:** Node.js (Express)
- **Banco de Dados:** PostgreSQL
- **Autenticação:** JWT (JSON Web Token)
